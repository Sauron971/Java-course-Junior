# Java from Scratch to Junior + Interview Preparation

This repository contains practical tasks and projects that remained after completing the course on the Stepik platform:

**"Java from Scratch to Junior + Preparing for an Interview"**

The repository includes examples of code, completed exercises, and practice projects created during the learning process.

Also included are course completion certificates in English and Russian.

---

## Topics studied during the course:

1. Introduction to Java
2. [Java Syntax](https://github.com/Sauron971/Java-course-Junior/tree/main/Course/1/)
3. [Object-Oriented Programming (OOP)](https://github.com/Sauron971/Java-course-Junior/tree/main/Course/2/)
4. Unit testing with JUnit and Gradle
5. [Collections Framework](https://github.com/Sauron971/Java-course-Junior/tree/main/Course/3/)
6. [Generics](https://github.com/Sauron971/Java-course-Junior/tree/main/Course/4/)
7. [Concurrency and Multithreading](https://github.com/Sauron971/Java-course-Junior/tree/main/Course/5)
8. [Stream API](https://github.com/Sauron971/Java-course-Junior/tree/main/Course/6)
9. [Input/Output Streams and File Processing](https://github.com/Sauron971/Java-course-Junior/tree/main/Course/7)
10. Java Core

---

Each topic included practical tasks to reinforce the acquired knowledge.

During the course, the following skills were practiced:

* writing Java applications;
* working with OOP principles;
* using collections;
* creating unit tests;
* working with generics;
* multithreading;
* using Stream API;
* working with files and input/output streams.

The final course test was successfully completed.
